# POPVIL Facebook 运动装短视频 Hook 选题库

## 打开方式

1. 保持 `index.html` 与 `hooks-data.js` 在同一文件夹。
2. 双击 `index.html`，即可用 Chrome、Edge 或其他现代浏览器本地打开。
3. 无需安装软件、无需联网即可使用搜索、筛选、排序和详情展开；只有点击“参考来源”时需要联网。

## 页面功能

- 关键词搜索：覆盖 Hook、中文释义、人群、痛点、切入角度、风险、标签和来源。
- 分类筛选：按场景跨度、痛点纠错、细节揭晓、购买教育等内容结构筛选。
- 风险筛选：快速查看低/中/高风险选题。
- 推荐指数排序：默认从高到低；推荐指数由相关性、传播性、实用性、风险可控性四项评分综合得出。
- 详情展开：查看建议开场画面、适合人群、用户痛点、内容切入、推荐理由、风险与来源信号。
- 复制 Hook：支持一键复制英文开头文案；浏览器限制剪贴板时可手动复制。

## 数据口径

- 本期日期：2026-09-15。
- 研究窗口：2026-09-08 至 2026-09-15，美国市场。
- TikTok 的公开播放、点赞、分享与收藏数据于 2026-09-15 核验。
- Instagram 页面未公开显示播放量时，保留可见点赞/评论信号，并标记“播放量待核实”。
- Hook 是基于近期内容结构重新创作的 POPVIL 版本，不应逐字复制参考品牌文案。
- 播放表现不能保证复现；正式投放前仍需结合 POPVIL 自有 CTR、ROAS、3 秒留存和素材疲劳数据复测。

## 每日更新方法

打开 `hooks-data.js`，在 `window.HOOKS = [...]` 数组中新增或替换选题。每条记录需保留以下字段：

- `hook`、`translation`
- `category`、`audience`、`painPoint`、`angle`、`reason`
- `risk`、`riskLevel`、`riskTags`
- `openingShot`
- `source`（标题、平台、链接、发布时间、公开信号、核实状态）
- `scores`（相关性、传播性、实用性、风险可控性，均为 1–5）
- `recommendation`（推荐指数，1.0–5.0）

更新后保存文件并刷新网页即可。为避免重复，建议使用唯一编号（如 `HK-021`），并在发布前再次打开每个来源链接复核。
